# Ruixiang Jiang — academic website

Source for the personal academic website at https://songrise.github.io/.

The current site consists of `index.html` (homepage and publications), `home.css` (homepage styles), and `blog.html` (research notes). The homepage uses local EB Garamond fonts, a paper texture, and illustrated publication entries. Selected web assets are in `images/bookish/` and `images/papers/`; the original artwork and image selection notes are kept alongside them. The CV is in `data/CV.pdf`.

The earliest version of this site adapted [Jon Barron's academic website](https://jonbarron.info/). That source inspired the original layout and is acknowledged here.

Reusable texture generators and site asset checks are documented in [`src/README.md`](src/README.md).
